# AI 课程笔记自动出题网站 (AI Quiz Generator)

一个基于大语言模型（LLM）的课程复习自测工具。粘贴课程笔记，AI 自动生成带解析的选择题，支持在线答题、自动判分、错题记录与学情可视化分析，帮助你把“看完就忘”的笔记变成可练习的题库。

## ✨ 核心功能
- 📝 **智能出题**：粘贴笔记，调用大模型生成高质量题目，自带详细中文解析。
- 🎯 **学科/年级/题型筛选**：支持不同学科、年级，以及**单选/多选**定制。
- ✅ **在线自测**：实时判分，直观展示对错与解析。
- 📕 **错题本**：答错的题目自动存入 SQLite 数据库，按学科和知识点双层分类。
- 🔄 **错题重练闭环**：支持**随机重练**或**单独狙击某道错题**。答对后可自主选择移出错题本。
- 📊 **学情分析**：通过 Plotly 环形图动态展示各学科、各知识点的薄弱分布。
- 🤖 **纯本地离线部署**：基于 Ollama 本地大模型，断网可用，隐私安全。

## 🛠️ 技术栈
- **前端**：Streamlit
- **大模型**：Ollama (本地 qwen2.5:7b) / 兼容 OpenAI 接口的云端 API
- **数据存储**：SQLite (sqlite3)
- **数据分析**：Pandas, Plotly
