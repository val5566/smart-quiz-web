# AI 课程笔记自动出题网站

基于大语言模型的课程复习自测工具。粘贴课程笔记，AI 自动生成带解析的选择题，支持在线答题、自动判分、错题本记录与知识点薄弱分析。

## ✨ 核心功能
- 📝 **智能出题**：粘贴笔记，调用大模型生成高质量单选题，自带详细解析。
- ✅ **在线自测**：实时判分，直观展示对错与解析。
- 📕 **错题本**：答错的题目自动存入 SQLite 数据库，支持去重，按知识点分类。
- 📊 **学情分析**：通过 Plotly 图表动态展示薄弱知识点分布。

## 🛠️ 技术栈
- **前端**：Streamlit
- **大模型**：ModelScope API (兼容 OpenAI 接口格式)
- **数据存储**：SQLite (sqlite3)
- **数据分析**：Pandas, Plotly
